[size=5][b]BepInEx Pack for Mimic Party[/b][/size]
[b]Pack 1.0.1 · configured and maintained by arribbaa[/b]

Original loader: BepInEx team and contributors.
BepInEx 6.0.0-be.788, Unity IL2CPP Windows x64, with Mimic Party Interop Bootstrap 1.0.1, hidden-console preset and disk logging. All 228 original upstream BepInEx files remain byte-for-byte unchanged.

[size=4][b]Supported builds[/b][/size]
Pack 1.0.1 explicitly supports the captured Mimic Party Windows / Steam fingerprints for v0.1.73 (11 September 2026) and v0.2.3 (22 September 2026). Unknown fingerprints are rejected without modifying generated interop files.
[url=https://github.com/LocoPablito/BepInEx-Pack-for-Mimic-Party/blob/main/COMPATIBILITY.md]Exact hashes and verification details[/url]

[size=4][b]Installation / update[/b][/size]
1. Close the game and use Steam > Manage > Browse local files.
2. Extract the runtime Pack ZIP into the folder containing Mimic Party.exe.
3. Updating from 1.0.0: allow replacement of BepInEx/patchers/MimicParty.InteropBootstrap.dll.
4. Install [url=https://www.nexusmods.com/mimicparty/mods/2]Modding Core[/url] only when your chosen feature mod requires it, then the feature mod.
5. Launch normally through Steam and allow interop regeneration to finish when the game changed.

[size=4][b]What 1.0.1 fixes[/b][/size]
Mimic Party v0.2.3 changed GameAssembly.dll and global-metadata.dat. Bootstrap 1.0.0 rejected the new fingerprint, leaving duplicate empty helper names in the locally generated UnityEngine.CoreModule.dll; the IL2CPP chainloader then stopped before normal plugins loaded.

Bootstrap 1.0.1 adds the exact verified v0.2.3 fingerprint and generated-CoreModule layout. It remains fail-closed: both fingerprint and structural checks must match before the three known duplicate TypeDef names are repaired. No native game file is modified.

[size=4][b]Logging[/b][/size]
Disk log: BepInEx/LogOutput.log. Console remains hidden by default.
