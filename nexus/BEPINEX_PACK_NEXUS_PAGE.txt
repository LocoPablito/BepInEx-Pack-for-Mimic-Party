[size=4][b]Installation / update[/b][/size]
1. Close the game and use Steam > Manage > Browse local files.
2. Extract the runtime Pack ZIP into the folder containing Mimic Party.exe.
3. Updating from 1.0.0 or 1.0.1: allow replacement of BepInEx/patchers/MimicParty.InteropBootstrap.dll.
4. Install [url=https://www.nexusmods.com/mimicparty/mods/2]Modding Core[/url] only when your chosen feature mod requires it, then the feature mod.
5. Launch normally through Steam and allow interop regeneration to finish when the game changed.

[size=4][b]What 1.0.2 fixes[/b][/size]
Mimic Party v0.2.33 changed GameAssembly.dll and global-metadata.dat again. Pack 1.0.1 correctly rejected the unknown fingerprint, which meant the generated CoreModule compatibility repair was not allowed to run and the IL2CPP chainloader could not load normal plugins.

Bootstrap 1.0.2 adds the exact captured v0.2.33 fingerprint plus the independently verified generated-CoreModule layout. It remains fail-closed: both the fingerprint and structural checks must match before the three known duplicate TypeDef names are repaired. No native game binary is modified.

The v0.2.33 live acceptance test passed: Bootstrap 1.0.2 reported compatibility ready, and the normal IL2CPP plugin chain loaded successfully.

[size=4][b]Logging[/b][/size]
Disk log: BepInEx/LogOutput.log. Console remains hidden by default.
