BepInEx 6.0.0-be.788 for Mimic Party Windows x64 / Unity IL2CPP, with Interop Bootstrap 1.0.2.

[size=4][b]v0.2.33 update[/b][/size]
Mimic Party changed its GameAssembly and metadata again. Pack 1.0.2 adds an explicitly verified, fail-closed compatibility profile for the new v0.2.33 build while retaining the older supported profiles.

The generated UnityEngine.CoreModule layout was independently checked before adding support. The bootstrap only renames the three validated empty duplicate helper TypeDef names and does not modify native game binaries.

[size=4][b]Installation[/b][/size]
1. Close the game.
2. Extract the runtime ZIP into the folder containing Mimic Party.exe.
3. Replace the existing BepInEx/patchers/MimicParty.InteropBootstrap.dll when prompted.
4. Launch through Steam and allow interop generation to finish.
